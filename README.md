# 游戏内日志收集与分析系统

## 项目描述

游戏内日志收集与分析系统的bug修复项目。核心模块 `logging/aggregator.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 日志收集完全没做日志都在各台服务器上
- 日志聚合完全没做不同格式的日志混在一起
- 日志搜索完全没做只能用grep搜
- 日志分析完全没做不能统计错误率和响应时间
- 告警完全没做ERROR日志也不通知

## 运行测试

```bash
python -m pytest tests/test_log_aggregator.py -q
```

修复目标：所有 15 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
